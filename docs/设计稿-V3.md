## 1. 叙事总线：一部河谷史诗，五幕

整站是一条时间河。访客从「为什么要走」一路看到「他们之前谁在这里」。

```
序章 Prologue          一句引语，一个河谷，一束光
  ↓
第一幕 西迁 1764        为什么走、怎么走、三年三千里     ← 底图 A
  ↓
第二幕 筑城 1762–1882   九城起落：营建浪潮、战火、重生   ← 底图 B(古风河谷图+时间轴)
  ↓
第三幕 卡伦人家         制度 + 18 座卡伦逐座档案 + 戍卒日常
  ↓
第四幕 更深的河谷       遥感发现的古墓葬：比锡伯早两千年的人
  ↓
第五幕 我们如何工作     AI 遥感 → 田野 → 扫描 → 博物馆
  ↓
尾声                   星光留言墙
```

设计意图：第一幕回答 **why**(帝国边防与民族迁徙)，第二幕回答 **what changed**(河谷景观被重塑)，第三幕回答 **who**(一个个具体的人如何生活)，第四幕回答 **before**(时间的纵深)，第五幕回答 **how we know**(方法论，建立可信度)。

## 2. 底图体系重构(核心变更,2026-09-12 已原型验证)

### 2.1 原则

- **全站不再出现任何现代底图**(现代路网、现代地名、卫星影像一律移除)。
- 全站只有两套底图，各自为一种叙事服务；底图本身就是展品。
- 技术底座仍是 MapLibre GL v5 + globe 投影(已验证稳定),但 style 完全自绘。

### 2.2 古地图获取的现实结论(实测)

为拿到真实古地图原图，已实测以下通道，**当前开发环境全部不可行**:

| 通道 | 结果 |
| --- | --- |
| Wikimedia Commons(upload.wikimedia.org) | 连接超时，不可达 |
| 美国国会图书馆 www.loc.gov / getarchive 镜像 | Cloudflare 拦截(403) |
| LOC 图像瓦片服务 tile.loc.gov | 可达但无法定位资源 ID(404),官网目录页被拦截无法反查 |
| archive.org | 不可达 |
| David Rumsey | 可达，但授权为 **CC BY-NC-SA(禁商用)**,不建议使用 |

**结论：不等待真实古地图扫描件，主方案改为「程序化古风底图」**——用现代开放地理数据(OpenMapTiles 自然要素 + Mapterhorn 地形)+ 自绘古舆图风格渲染，**生成式地做出一张干净的、古地图气质的底图**。真实古地图降级为可选增强层(见 2.4)。

### 2.3 主方案:程序化古风底图(✅ 已生成原型验证)

已编写自绘 style JSON 并实际渲染验证，两张原型截图随本稿交付:

- **底图 A「西迁之路」**(欧亚尺度):宣纸底色(#ece1c5)+ 暖褐山体晕染(Mapterhorn DEM 重着色,exaggeration 0.42)+ 灰绿水面/水系(#b7c4b2)+ 朱砂虚线路线(#a63a2b)+ 中英双语历史地名标注(盛京/库伦/乌里雅苏台/科布多/塔尔巴哈台/伊犁……自维护 GeoJSON)。实测效果：完全无现代地图的"脏"和"乱",古卷气质成立。
- **底图 B「伊犁河谷」**(河谷尺度):同一风格放大,pitch 35–45 时天山山体呈传统舆图式立体晕染，伊犁河与喀什河水系清晰，干净利落。

技术要点(已验证):OpenFreeMap 矢量瓦片仅取 landcover/water/waterway/boundary(国界细虚线)/mountain_peak 图层;**道路与居民点标签全部不渲染**;中文标注 glyph 渲染正常;需在正式版过滤西里尔字母的山峰/水系标签(原型中可见，正式版按语言白名单过滤)。

### 2.4 增强层:真实古地图叠加(可选，非阻塞)

若日后拿到 1809《西陲总统事略》九城图 / 1864《嘉峪关外镇迪伊犁合图》高清扫描件(用户上传，或在可访问 Wikimedia/LOC 的环境下载):

- 本地 GDAL 控制点配准 → 切片 → 作为半透明叠加层铺在古风底图上，透明度滑块交给访客;
- 图层结构已为此预留(叠加层插入在晕渲之上、数据点之下),**任何时候拿到图都能无缝接入，不重构**。

### 2.5 时间轴交互(第二幕灵魂)

第二幕底部一条金色时间轴:**1762 → 1766 → 1871 → 1882**。

- 拖动/滚动时，九城在地图上**按时序点亮、变暗(1871 毁城)、重生(1882)**;
- 卡伦线随时间轴展开；
- 每到一个时间节点，侧边浮现该时期的全局解说(100 字内)。

## 3. 第一幕「西迁 1764」详细设计

### 3.1 分场结构

| 场次 | 内容 | 形式 |
| --- | --- | --- |
| 1-1 帝国的新边疆 | 1750s 平定准噶尔后伊犁河谷空虚，清廷设伊犁将军(1762),需要能屯垦自给的常驻兵源 | 文案卷轴 + 郎世宁《平定伊犁受降》图(PD) |
| 1-2 征调令 | 1764 年征调盛京锡伯官兵眷属西迁戍边：为什么是锡伯(骑射传统、可携带家眷、编牛录) | 文案 + 沈阳锡伯家庙「西迁之路」雕塑照片(CC BY-SA,已核实来源) |
| 1-3 三千人的远行 | 规模(约三千余官兵眷属)、队伍构成、牛录组织、车辆牲畜 | AIGC 全景长卷 |
| 1-4 路线八站 | 盛京→张家口→库伦→乌里雅苏台→科布多→塔尔巴哈台→(阿尔泰/额敏河谷)→伊犁，逐站卡片 | 底图 A 交互 |
| 1-5 抵达与扎根 | 1766 年前后抵达，安置察布查尔，编锡伯营八牛录，挖渠屯田 | 文案 + AIGC(抵达/落户场景) |
| 1-6 数字里的迁徙 | 一块「数据碑」:里程、时长、人数、牛录数(全部标注史料口径与存疑处) | 信息卡 |

### 3.2 站点卡片规格(每站 150–250 字)

每站字段：`站名(中英/历史地名)`、`在此发生了什么`(路线选择、补给、越冬、减员等,150–250 字,存疑标注)、`配图`(AIGC 场景)、`地图动作`(flyTo + 路线段点亮)。

### 3.3 文案基调

以「一封信/口述」质感写，例：「农历四月，队伍在乌里雅苏台停下越冬。大雪封山前，他们必须把牲畜喂饱。」——所有具体数字若无出处，标注「口述史说法，文献记载不一」。

## 4. 第二幕「筑城」详细设计

### 4.1 结构

题解(为什么筑城：伊犁将军驻防体系) → 时间轴贯穿的九城档案 → 总览(九城+牛录+卡伦的体系图)。

### 4.2 九城「档案卷」规格(每城一份)

| 要素 | 规格 |
| --- | --- |
| 正文 | **300–500 字**(中英双语),回答:为何建、谁驻守、城里有什么、经历了什么、今天剩什么 |
| AIGC 复原图 | 每城 1 张(已有,风格统一) |
| 历史影像 | 有则必配(分配见下表),图注写明来源与授权 |
| 古地图局部 | 从 1809/1864 古地图裁出该城标注局部，作为「证据图」 |
| 年代徽标 | 年份;存疑则「c. 1762–66 · 年代存疑」 |
| 现状照片 | 有遗址者配现状照(惠远古城遗址、钟鼓楼等,CC BY-SA 已核实) |

### 4.3 历史影像分配(基于已核实清单)

| 城 | 历史影像(已核实授权) |
| --- | --- |
| 惠远老城 | 1809 九城图局部；惠远古城遗址现状照(CC BY-SA) |
| 惠远新城 | 钟鼓楼现状照(CC BY-SA);伊犁将军府照片(CC BY-SA) |
| 绥定 | Lansdell 1882 城门版画(PD) |
| 宁远(今伊宁) | Orden 1880s 固勒扎宣礼塔照片(PD);Lansdell 塔兰奇清真寺版画(PD);Mannerheim 巴扎街景(CC BY 4.0) |
| 惠宁/熙春/塔勒奇/瞻德/广仁 | 无公版影像(已如实确认)→ 用古地图局部 + AIGC,文案中说明「影像无存」本身也是叙事 |

### 4.4 时间轴叙事脚本(四拍)

1. **1762–1766 营建浪潮**：九城按营建次序逐一点亮，河谷从牧场变成城郭;
2. **1871 庚子之变**：沙俄入侵，惠远老城等毁——对应城点**变暗/转灰**,文案讲战火;
3. **1882 收复与重生**:《伊犁条约》后重建惠远新城，钟鼓楼立起;
4. **今天**：遗址与地名——「城不在了，名字还在」。

## 5. 第三幕「卡伦人家」详细设计

### 5.1 结构(四层)

1. **制度篇**：卡伦是什么(已有文案，保留深化):瞭望/稽查/传信/护路；常设与移设；锡伯营换防制;
2. **防线篇**:1864 年 LOC 合图叠加，18 座卡伦沿边界线展开成「一条看得见的防线」;
3. **逐座档案篇**(核心):18 座卡伦每座一份档案卡;
4. **生活篇**:4 个 AIGC 场景(瞭望/操练/屯垦/冬夜，已有)嵌入档案流中。

### 5.2 卡伦档案卡规格(每座 150–250 字 + 图)

| 字段 | 说明 |
| --- | --- |
| 名称与语源 | 如「头湖」「梧桐孜」「纳旦木」等蒙古语/突厥语地名含义(可查则写,不可查则标注「语源待考」) |
| 位置与防区 | 所属线路(沿边界东南/西北段)、相邻卡伦、间距里程 |
| 谁在这里 | 驻守来源(锡伯营某牛录轮驻/索伦营辖区等),有记载则写,无记载用制度性描述 + 标注 |
| 保存等级 | 沿用现有 0–5 级数据，可视化 |
| 图 | AIGC 戍守场景(按保存等级/地理特征区分)+ 1864 合图标注裁切(证据图)+ 现状照片(如有) |
| 今址 | 对应现代村镇(从 CSV 坐标反查),「今天的这里」一句话 |

### 5.3 诚实性设计(关键)

18 座卡伦的逐座专史在现存公开史料中**并不都有记载**。设计对策：
- 每座卡的「谁在这里」采用「制度事实 + 地理事实 + 推测标注」三层写法，推测内容明确标「(推测，依据防区制度)」;
- 设「史料空白」徽章——空白本身被讲述:「这座卡伦没有留下专属记载，它和千百座边疆哨所一样，由无名戍卒看守。」这反而是动人的叙事点;
- **需要用户提供**:研究论文、田野照片、任何卡伦专项调查资料(见 §10)。

### 5.4 3D 模型位

保留 Sketchfab 嵌入位(iframe embed，支持标注热点);用户上传 Sketchfab 后替换占位 GLB。档案卡中 3D 模型作为「走进卡伦」入口。

## 7. 内容工程规范(本次升级的「内容太少」对策)

### 7.1 字数与素材标准

| 对象 | 正文字数(中文) | 必备素材 |
| --- | --- | --- |
| 西迁背景各场(1-1~1-6) | 150–300 | 每场至少 1 图(历史图/AIGC) |
| 路线每站 | 150–250 | AIGC 场景 1 张 |
| 九城每城 | **300–500** | AIGC + 历史影像(如有)+ 古地图局部 |
| 卡伦每座 | 150–250 | AIGC/证据图 + 现状照(如有) |
| 制度篇/生活篇 | 200–400 | 已有素材 |

### 7.2 「图-文-证」三栏制

每个叙事单元 = **图**(AIGC 复原，标「艺术复原」)+ **文**(正文)+ **证**(古地图裁切/历史照片，标来源授权)。三者至少占二，证据优先。

### 7.3 事实底线(沿用并强化)

- 不编造人名、日期、数字;无出处的一律标注存疑/口述/推测;
- 每单元文末可折叠「史料依据」小注(面向评审与专业访客，提升可信度);
- 全文英文先行，中文对照。

## 8. 视觉与交互系统

- **色系**:宣纸米白(#e8dfc9 用于卡面)、墨、朱砂(#a63a2b 标记)、金(#c9a45c 光线)——从 V2 的暗夜金调演进为「古卷夜色」双质感：地图区暗夜宣纸感，内容区卷轴米白;
- **字体**:Noto Serif SC + Playfair Display 沿用；历史地名考虑竖排装饰处理;
- **转场**：幕与幕之间用「卷轴展开/收起」过渡；地图淡入淡出切换底图 A/B;
- **性能**:19+ 张图全部 lazy-load;古地图切片 <5MB 预算。
